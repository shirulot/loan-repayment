# 提前还贷计算器

一个离线运行的 Flutter 提前还贷规划工具。应用根据商贷、公积金、现金流和提前还款记录生成滚动还款计划，帮助用户核对当前月供、预计提前还款额、贷款余额和预计结清月份。

应用不依赖业务服务器。贷款参数、现金流、提前还款记录和计划列设置保存在本机，当前适配 Android、macOS 与 Windows。

## 功能概览

- **双贷款类型计算**：分别计算商贷、公积金及合计的本金、利息、月供、余额和月供减少额；首页将当前贷款余额与初期贷款本金、利率分开显示。
- **动态还款计划**：从计算时的当前月份开始生成计划，不固定截止到某个年月；当商贷、公积金余额及待结转利息均清零后停止，实际提前还款造成提前结清时自动删除后续月份。
- **现金流计算**：记录本月收入、额外收入、每月生活费和自动计算的当月月供；可供提前还贷额按 `本月收入 - 当月月供 - 每月生活费 + 额外收入` 计算。
- **最近三笔提前还款**：用“金额 + 还贷日期”维护最近三笔交易，支持同一自然月多笔，并始终按日期从早到晚展示。新增一笔时移出日期最远的一笔；删除后会优先从计划中的已还记录补回一笔。区域摘要从还款计划表中选择“还款日期不晚于今天”的最近一笔，未来日期不参与。
- **计划与实际状态**：没有已录入实际金额时使用计划金额；录入某笔实际提前还款后，该笔显示“已结清”、锁定编辑并重新计算后续计划。未填写日期的记录仍会保留在相应月份，方便补录实际日期。
- **还贷日期与提前利息**：日期使用 `YYYY-MM-DD`，可通过中文日期选择器填写。提前还款当天应付利息单独列出，按 `提前还款本金 × 年利率 ÷ 360 × 已占用天数` 计算；商贷月供本身不额外叠加商贷转息利息，公积金仍保留剩余天数结转规则。
- **转息前月供与差额**：计划表展示不含银行账单校准、结转息和当月提前还款影响的基础月供，并根据基础月供计算减少额；`转息差额 = 月供合计 - 转息前月供`。
- **移动端界面**：首页采用现金流四宫格、参数折叠项和最近三笔预览；“还款计划”Tab 直接显示完整详情，表格支持横向滚动、居中紧凑显示和列设置。
- **金额脱敏**：首页与还款计划详情共享脱敏开关，开启后金额和还贷日期显示为星号，关闭后恢复显示。
- **数据导入导出**：详情页支持导出 Excel 兼容 `.xls`、CSV 和 JSON；JSON 备份可导入并恢复贷款参数、现金流、提前还款记录和实际还款数据。
- **本地缓存与迁移**：编辑内容自动保存，下次启动优先读取最近缓存；新安装不预置金额。Android 已配置系统 Auto Backup 与设备迁移规则，是否能在删除重装后恢复取决于系统备份能力。
- **中文本地化**：应用和日期选择器使用中文界面，避免月份显示为英文。

## 使用方式

1. 新安装时金额字段为空。首页填写贷款开始日期、贷款总年限、初期商贷/公积金本金、利率和现金流；贷款开始日期与总年限同时有效时，剩余期数会根据当前日期自动计算，否则沿用手动剩余期数。
2. 在“最近三笔提前还款”中填写每笔金额和日期。日期支持手动输入 `YYYY-MM-DD`，也可以点击日历选择；计划金额按已维护的最近交易优先，其他月份按可供提前还贷额计算，并随着正常月供下降而动态变化。摘要仅从今天及以前的还款日期中取最近一笔。
3. 点击“应用并重算”确认贷款参数，提前还款记录的修改会直接同步到还款计划。实际还款金额以对应记录为单位维护；同月多笔会在详情表中展开成多行。
4. 切换到“还款计划”Tab 查看完整计划。默认显示商贷、公积金、合计月供及减少额、预期提前、还贷日期/状态、当日提前利息、转息前月供、转息差额和余额等字段。
5. 在详情页可开启金额脱敏、选择显示列、导出文件或导入 JSON 备份。列显示偏好会单独缓存，并在新增列时自动迁移一次。

> 计划结果用于辅助规划，实际扣款、提前还款利息、违约金和最终结清金额以银行合同及还款后账单为准。

## 数据存储与备份

- 贷款状态文件：应用 Documents 目录下的 `loan-repayment-plans/loan-plan-state.json`。
- 计划列设置：同目录下的 `loan-plan-column-settings.json`，与贷款数据分开保存。
- 导出文件目录：应用 Documents 目录下的 `loan-repayment-plans`。
- JSON 导出包含贷款参数、实际提前还款数据、提前还款事件和计划明细，可用于跨设备手动备份与恢复。
- CSV 和 Excel 兼容文件包含公历月份、两类月供及减少额、预期/实际提前还款、还贷日期、当日提前利息、转息前月供、转息差额、基础月供减少额和余额；这两种格式仅用于查看，不能导回应用。
- 导出使用固定文件名，同一格式再次导出会覆盖该格式的上一次导出文件。

## 计算说明

### 普通月供

- 计划首行是当前余额校准行，正常月供从下一行开始计算；首页“当月月供”读取首个正常月供行，避免显示为 0。
- 商贷本金按当前商贷余额和剩余期数平均分摊。
- 商贷利息按每一行对应的上一个完整自然月计息：

  `商贷利息 = 当行商贷余额 × 商贷年利率 ÷ 360 × 上一个完整自然月天数`

  例如 9 月月供使用 8 月的 31 天，10 月月供使用 9 月的 30 天，11 月月供使用 10 月的 31 天。商贷月供为商贷本金与该利息之和。

- 公积金按余额、年利率和剩余期数计算正常月供；有日期的提前还款仍会按剩余天数计算待结转利息。
- `月供合计 = 商贷月供 + 公积金月供`。
- `转息差额 = 月供合计 - 转息前月供`；转息前月供只使用当月余额、剩余期数和两类利率，不包含银行账单校准、结转息或当月提前还款后的余额影响。

### 提前还款

- 计划中的提前还款金额优先取最近三笔记录；未维护对应记录时，使用可供提前还贷额。自动计算的金额向上取整到十元，录入的交易金额按原值计算，并以剩余本金为上限。
- 同月多笔提前还款按日期排序逐笔计算，每个自然月的正常月供只扣除一次：多笔场景在第一笔提前还款后按剩余余额重新计算，并由第一笔明细计入；后续明细仍展示按前序余额重算的月供信息，但只扣各自提前还款，单笔场景仍由计划行计入。正常月供分别扣除商贷和公积金本金并消耗一期剩余期数；这些交易仍归入当前自然月，详情表会展示实际计入的月供组成和每笔交易后的余额。
- 最近还款摘要按完整计划表的还款日期判断，而非按月份或记录添加顺序：在所有 `还款日期 <= 今天` 的记录中取日期最大的那一笔。
- 实际提前还款只记录偿还本金，提前还款当天利息由应用单独计算，不混入本金输入；实际金额覆盖对应计划金额后，余额、月供、减少额和结清时间全部重新生成。
- 金额格式保留两位小数，千分位分隔符不会出现在数字首尾。

## 开发环境

- Flutter SDK：Dart `^3.12.2`
- 主要依赖：`flutter_localizations`、`lunar`、`path_provider`、`file_picker`
- 平台：Android、macOS、Windows

## 运行

在项目根目录执行：

```bash
flutter pub get
flutter devices
flutter run -d <设备ID>
```

常用目标示例：

```bash
flutter run -d macos
flutter run -d windows
flutter run -d <Android设备ID>
```

## 构建

```bash
flutter build apk --release
flutter build macos --release
flutter build windows --release
```

- Android Release APK 输出：`build/app/outputs/flutter-apk/app-release.apk`。
- macOS 构建需在 macOS 上执行；Windows 构建需在 Windows 上执行。

## 验证

```bash
flutter analyze
flutter test
```

测试覆盖核心还款计算、360 天商贷计息、按日期计算提前还款利息、公积金结转息、转息前月供与转息差额、现金流与贷款期限换算、同月多笔提前还款、动态结清、缓存/备份恢复、金额格式化、脱敏和详情表交互。
